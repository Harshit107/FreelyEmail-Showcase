# REQUIREMENTS.md — FreelyEmail Showcase

## Milestone 1: Comprehensive Developer Showcase & Interactive Portal

### Functional Requirements
- **FR-1: Ecosystem Overview**: Clean introduction to FreelyEmail, its problem statement (frictionless transactional emails for Node.js apps), key stats, and architecture principles.
- **FR-2: Architecture Visualizer**: Visual component/layer breakdown (Routes -> Controller -> Service -> Nodemailer + MongoDB fail-safe persistence) and dual-project interaction diagram.
- **FR-3: Interactive API Explorer**: Interactive documentation for all 4 API endpoints (`/api/v1/emails/send`, `/api/v1/emails/otp/send`, `/api/v1/emails/otp/request`, `/api/v1/emails/verification/link`), with payload inputs, test execution simulation, and response inspection.
- **FR-4: SDK Showcase & Code Generator**: Copy-paste ready snippets in CommonJS, ESM, and TypeScript, demonstrating `FreelyEmailClient` configuration and method calls (`sendNotification`, `sendOtp`, `requestOtp`, `sendLinkVerification`).
- **FR-5: Live Email Template Previewer**: Interactive iframe or sandbox rendering the exact HTML output generated by FreelyEmail's OTP, verification link, and notification email templates with customizable parameters (brand color, app name, OTP, valid minutes).
- **FR-6: Dependencies & Technical Decisions**: Deep dive into the zero-dependency SDK design, why native fetch was chosen over axios, SMTP pooling singleton, error handling hierarchy (`APIError`, `FreelyEmailAPIError`), and security measures (`helmet`, `cors`, `express-rate-limit`, header sanitization).
- **FR-7: Developer & Setup Guide**: Step-by-step instructions for running `FreelyEmail-API` locally (`npm run dev`), setting up `.env`, running the Node SDK, and publishing to NPM.
- **FR-8: Responsive Developer-Portal UI**: Top header with theme switcher (Dark/Light), search/filter for quick discovery across topics, section navigation, and fluid mobile/desktop layout.
